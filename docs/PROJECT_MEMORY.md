# Casa Paraiso Project Memory

> Last reviewed: 2026-10-26
> Role: orientation and routing; verify current source before changing behavior.

## Current Shape

Casa Paraiso is a Laravel 12 server-rendered web application using MariaDB 10.11 LTS. It supports customer, receptionist, therapist, administrator, and super-administrator workspaces. Core modules are services, staff and customers, weekly availability, calendar appointments, transactions, attendance, commissions, feedback and sentiment, RFM rewards, settings, reports, and CSV export.

Earlier native-client, versioned API, device-token, database, tunnel, and hosted-pilot integrations are retired. The previous repository and database infrastructure remain archival rollback sources only.

The local `redesign` branch carries the presentation-only Modern Resort redesign ([REDESIGN_MODERN_RESORT.md](REDESIGN_MODERN_RESORT.md)). On 2026-10-26 the user chose to put `redesign` live: casaparaiso.site serves a release packaged from it, while `main` stays unmerged as the stable rollback version. Do not merge or push `redesign` without the user's explicit decision. Soft tone accents come from `.casa-tone-*` classes (`--tone`/`--tone-bg`). Metric grids cycle them by position, and drawer chips, header bands and charts use them too; see the Color accents section of the redesign doc. Its shape and elevation tokens (`--radius-casa-*`, `--shadow-casa-soft`, `--color-casa-glass`, status colors) live in the `@theme` block of `resources/css/app.css`. Page CSS consumes them. The frosted `casa-topbar casa-glass-bar` top bar and the deep palm `casa-drawer` overlay replace the sidebar.
